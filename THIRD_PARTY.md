# Componentes de terceiros

Este repositório deriva de
[addy-dclxvi/i3-starterpack](https://github.com/addy-dclxvi/i3-starterpack).
As alterações locais não substituem os direitos e avisos dos autores dos
componentes originais.

## Incluídos no repositório

- **Nordic GTK theme**, de Eliver Lara. A licença acompanha os arquivos em
  `.local/share/themes/Nordic-master/LICENSE`.
- **Symbols Nerd Font**, derivada do trabalho de Ryan L. McIntyre. A licença
  acompanha os arquivos em `.local/share/fonts/LICENSE`.
- **Nordic para Kvantum**, identificado nos próprios arquivos como trabalho de
  Eliver Lara. A origem e a licença devem ser confirmadas antes de qualquer
  redistribuição fora deste fork.

## Dependência externa

- **Papirus Icon Theme** não é mais copiado para o repositório. Deve ser
  instalado pelo gerenciador de pacotes da distribuição, preservando os avisos
  e atualizações fornecidos pelo pacote.
